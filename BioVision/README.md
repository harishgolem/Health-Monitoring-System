# BioVision — Medical Image Learning Demo

A small Python/Tkinter interface demonstrating a basic visualization workflow using **synthetic shapes only**.

## Run
`python main.py`

## Build a Windows EXE
Run `build_exe.bat` on Windows after installing Python 3.10+.

## Research scope and limitations
- The current demo does not use actual medical images, patient data, or an ML classifier.
- It is not a clinical tool and must not be presented as diagnosing disease.
- Future work: use a properly licensed public dataset, document the split, compare a baseline model, report metrics, and discuss false positives/false negatives.
