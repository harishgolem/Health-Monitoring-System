# Health Monitoring System

A Python-based health monitoring dashboard prototype developed to explore data visualization and software applications in healthcare technology.

## Overview

The Health Monitoring System demonstrates how a simple desktop application can display physiological measurements through a graphical user interface. The current prototype uses simulated data to illustrate how readings and trends could be presented.

## Features

- Desktop graphical interface using Python and Tkinter
- Simulated pulse-rate readings
- Simulated blood oxygen saturation (SpO₂) readings
- Simulated temperature readings
- Data visualization through a simple trend graph
- Refresh functionality for generating new demo readings

## Technologies Used

- Python
- Tkinter
- Random data generation
- Matplotlib-style data visualization concepts implemented with Tkinter Canvas

## Getting Started

### Prerequisites

- Python 3.10 or later
- Tkinter, normally included with standard Python installations

### Run the Application

1. Clone the repository:

   ```bash
   git clone https://github.com/harishgolem/Health-Monitoring-System.git
   ```

2. Open the project directory:

   ```bash
   cd Health-Monitoring-System
   ```

3. Run the application:

   ```bash
   python main.py
   ```

If your entry-point file has a different name, replace `main.py` with the correct filename.

## Project Purpose

This project is a learning prototype for exploring Python GUI development, data presentation, and potential applications of computing in healthcare.

## Limitations

- All displayed readings are simulated, not collected from real sensors.
- The application is not a medical device.
- It does not provide medical advice or diagnose health conditions.
- Real-world use would require sensor integration, testing, and appropriate validation.
