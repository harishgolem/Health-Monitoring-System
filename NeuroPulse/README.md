# NeuroPulse — EEG Signal Explorer

A small Python/Tkinter learning demo that visualizes a **simulated** EEG-like waveform.

## Run
`python main.py`

## Build a Windows EXE
Run `build_exe.bat` on Windows after installing Python 3.10+.

## Research scope and limitations
- The waveform is simulated; it is not collected from a person or a medical device.
- This is an educational signal-visualization prototype, not a diagnostic or treatment tool.
- Do not describe it as detecting ADHD or any medical condition.
- Future work could load appropriately licensed, publicly available EEG datasets and document preprocessing and evaluation.
