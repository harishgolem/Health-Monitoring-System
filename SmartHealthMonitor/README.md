# Smart Health Monitor — Sensor Dashboard Demo

A Python/Tkinter dashboard showing randomly simulated pulse, SpO₂, and temperature values.

## Run
`python main.py`

## Build a Windows EXE
Run `build_exe.bat` on Windows after installing Python 3.10+.

## Research scope and limitations
- Values are randomly simulated and are not measurements from a person or a sensor.
- This is not a medical device and does not provide health advice or diagnosis.
- Future work could connect appropriate sensors, validate their readings, document calibration, and handle missing/noisy data.
